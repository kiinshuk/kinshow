# AGENTS.md

## Project

Kinshow — React 18 + Vite movie/TV discovery SPA. Light Facebook/Letterboxd theme,
sharp corners (`border-radius: 0`), accent `#1877f2`. Deployed on Vercel.

## Commands

- `npm run build` — prebuild fetches contributors, then `vite build` + prerender
- `npm run contributors` — manually refresh `src/data/contributors.json`
- No lint/typecheck configured.

## Merge checklist (important)

When merging a contributor's PR (merge commit, squash, or via `gh pr merge`):

1. Leave a comment thanking them and **telling them they are now listed on the
   About page** (https://kinshow.vercel.app/about) as a contributor, with their
   avatar and contribution count.
2. No manual edit of the contributors list is needed — it auto-refreshes on the
   next build and hourly via the Update contributors workflow.

## Contributors system

- Data: `src/data/contributors.json` (login, avatar, contributions, owner flag)
- Rendered in: `src/pages/About.jsx` → "Contributors" section (05)
- Generated by: `scripts/fetch-contributors.mjs` (GitHub contributors API)
- Refresh cadence: every build (`prebuild` hook) + hourly GitHub Action
  (`.github/workflows/update-contributors.yml`, direct push with PR fallback)
- Bots (`*[bot]` logins) are filtered out; owner gets the "Owner" badge

## Gotchas

- PowerShell shell: no `&&`, no jq (use `ConvertFrom-Json`)
- Branch protection requires 1 review; admin bypass allowed for owner pushes
- Never sandbox player iframes
- TMDB is network-blocked locally; use TVmaze + OMDb only
